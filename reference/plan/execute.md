작업계획서의 TODO 리스트를 기반으로 작업을 실행해주세요.

## 대상 작업계획서 결정
아래 우선순위로 대상 작업계획서를 자동으로 결정해주세요:
1. **$ARGUMENTS에 경로가 있으면** → 해당 파일 사용
2. **현재 대화에서 작업계획서를 방금 다루었거나 언급했으면** → 해당 파일 사용
3. **위 모두 해당 없으면** → `docs/plans/` 에서 TODO가 미완료(`- [ ]`)인 가장 최근 파일 사용
4. 결정된 파일을 알려주고 맞는지 확인 후 진행해주세요

## 구현 규칙 (CLAUDE.md 준수)
- **Tizen 4.0+ / Samsung TV WebKit 호환성**을 지키세요 (지원되지 않는 최신 JS/CSS API 회피, 필요 시 폴리필)
- **`reference/` 폴더는 수정 금지** (다른 프로젝트 참고용 자료)
- **비디오 볼륨 정책**: `<video>`의 `volume`은 항상 1.0 유지, 음소거는 `muted`로만 제어
- 단순 작업에 과도한 방어코딩·로깅·주석을 넣지 말고 핵심만 간결하게 구현하세요

## 서브에이전트 위임
TODO 카테고리에 따라 적절한 서브에이전트(Task tool, `subagent_type`)에 위임해주세요:
- 코드 구현(JS/HTML/CSS) → `dev`
- Tizen/Samsung TV API 호환성 확인이 필요한 항목 → `ref`
- 테스트/품질 검증 → `qa`
- 코드 리뷰가 필요한 항목 → `review`
- 문서 갱신(CLAUDE.md 등) → `doc`
- 아키텍처/영향도 판단이 필요한 항목 → `plan`
- 단순 문서/설정 수정은 메인 에이전트가 직접 처리해도 됩니다
- 독립적인 항목은 병렬로 위임하세요

## 실행 규칙
1. 작업계획서의 `## TODO` 섹션을 읽어주세요
2. 아직 완료되지 않은 TODO 항목 (`- [ ]`) 을 확인해주세요
3. 다음 순서로 실행해주세요:
   - 우선순위 🔴 높음 → 🟡 보통 → 🟢 낮음
   - 선후 관계가 있는 항목은 의존성 순서 준수
   - 병렬 가능한 항목은 표시만 하고 순차 실행

## 실행 프로세스
각 TODO 항목을 처리할 때:

1. **시작 전**: 현재 작업할 TODO 항목을 알려주세요
2. **실행**: 해당 작업을 실제로 수행해주세요 (위 서브에이전트 위임 기준 적용)
3. **완료 후**: 작업계획서의 해당 TODO 항목을 체크해주세요
   - `- [ ]` → `- [x]` 로 변경
   - 완료 시각과 간단한 결과 메모 추가
4. **완료를 한 줄로 보고하고, 확인받지 말고 즉시 다음 항목으로 진행해주세요** (연속 실행)

## 자동 진행 중단 조건
다음 상황에서는 연속 실행을 멈추고 사용자에게 보고해주세요:
- 테스트/검증 실패를 2회 시도에도 해결하지 못한 경우
- 계획서에 없는 인터페이스(Contract) 변경이 필요해진 경우
- `reference/` 수정이 필요해 보이는 경우 (금지 영역)
- TODO 간 충돌로 계획 수정이 필요한 경우

## TODO 완료 표시 형식
```markdown
- [x] 🔴 T-001: 미디어월 슬라이드쇼 동기화 구현 (~2h)
  > ✅ 완료 (14:30) - play.js slideStateAt 추가, 시뮬레이터 확인
```

## 전체 완료 시
모든 TODO가 완료되면 최종 요약을 알려주세요:
```
🎉 작업 실행 완료!
📄 파일: docs/plans/plan-20260401-미디어월-동기화.md

✅ 완료: 12/12
📝 수정된 파일: 8개
🧪 검증한 시나리오: 4개
📖 업데이트된 문서: 2개
```

사용자가 선택하면 해당 작업을 즉시 실행하세요:
