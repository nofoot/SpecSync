작업계획서의 현재 진행 상태를 확인해주세요.

## 대상 작업계획서 결정
아래 우선순위로 대상 작업계획서를 자동으로 결정해주세요:
1. **$ARGUMENTS에 경로가 있으면** → 해당 파일 사용
2. **현재 대화에서 작업계획서를 방금 다루었거나 언급했으면** → 해당 파일 사용
3. **위 모두 해당 없으면** → `docs/plans/` 에서 가장 최근 수정된 파일 사용
4. 결정된 파일을 바로 사용해주세요 (상태 확인은 확인 없이 진행)

## 확인 내용
1. 작업계획서를 읽고 다음 상태를 분석해주세요:
   - 에이전트 검토 완료 여부 (`<!-- {에이전트 파일명} 추가 -->` 형식 주석 존재 확인, 예: `<!-- review.md 추가 -->`)
   - TODO 리스트 존재 여부
   - TODO 진행률 (완료/전체)
   - 우선순위별 진행 현황

2. 다음 형식으로 보고해주세요:
```
📋 작업계획서 상태
📄 파일: docs/plans/plan-20260401-로그인-API-리팩토링.md
📌 제목: 로그인 API 리팩토링

📊 진행 단계:
  ✅ 계획 생성 완료
  ✅ 에이전트 검토 완료 (3/3)
  ✅ TODO 리스트 생성 완료 (12건)
  🔄 실행 중 (7/12 완료, 58%)

📈 TODO 현황:
  🔴 높음: 4/4 완료
  🟡 보통: 3/5 완료
  🟢 낮음: 0/3 완료
```

## 다음 작업 제안 (선택형)
상태 보고 후 **미완료 TODO가 있으면**, 후속 작업을 텍스트로 안내하지 말고 **AskUserQuestion 도구로 선택지를 제시**해주세요.
사용자가 선택하면 해당 작업을 즉시 실행하세요:
- **남은 작업 실행** → `/plan:execute {작업계획서 경로}` 절차 실행
- **여기서 종료** → 추가 작업 없이 종료

모든 TODO가 완료된 상태면 선택지 없이 보고만 하고 종료하세요.
