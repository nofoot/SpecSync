검토 완료된 작업계획서를 기반으로 실행 가능한 TODO 리스트를 생성해주세요.

## 대상 작업계획서 결정
아래 우선순위로 대상 작업계획서를 자동으로 결정해주세요:
1. **$ARGUMENTS에 경로가 있으면** → 해당 파일 사용
2. **현재 대화에서 작업계획서를 방금 검토했거나 언급했으면** → 해당 파일 사용
3. **위 모두 해당 없으면** → `docs/plans/` 에서 가장 최근 수정된 파일 사용
4. 결정된 파일을 알려주고 맞는지 확인 후 진행해주세요

## 처리 절차
1. 작업계획서를 읽고 모든 섹션을 분석해주세요
2. 다음 기준으로 TODO 항목을 추출/생성해주세요:
   - `작업 단계` 섹션의 각 단계 → 개별 TODO 항목
   - `검토 체크리스트`에서 체크되지 않은 항목 → TODO 항목
   - 에이전트 검토에서 추가된 보완 사항 → TODO 항목
   - 문서 업데이트가 필요한 항목 → TODO 항목
   - 테스트 추가가 필요한 항목 → TODO 항목

3. 각 TODO 항목에 다음 정보를 포함해주세요:
   - 우선순위: 🔴 높음 / 🟡 보통 / 🟢 낮음
   - 카테고리: 코드 / 테스트 / 문서 / 설정 / 배포
   - 예상 소요: 간단한 시간 추정
   - 선후 관계: 먼저 완료되어야 하는 TODO 번호

4. 작업계획서의 `## TODO` 섹션을 아래 형식으로 업데이트해주세요:

```markdown
## TODO

### 코드 작업
- [ ] 🔴 T-001: {작업 내용} (~2h)
- [ ] 🔴 T-002: {작업 내용} (~1h, T-001 이후)
- [ ] 🟡 T-003: {작업 내용} (~3h)

### 테스트
- [ ] 🟡 T-004: {테스트 내용} (~1h, T-001 이후)
- [ ] 🟢 T-005: {테스트 내용} (~30m)

### 문서 업데이트
- [ ] 🟢 T-006: {문서 내용} (~30m)

### 설정 & 배포
- [ ] 🟡 T-007: {설정 내용} (~1h)
```

5. 업데이트 완료 후 요약을 알려주세요:
   ```
   ✅ TODO 리스트 생성 완료
   📄 파일: docs/plans/plan-20260401-로그인-API-리팩토링.md

   📊 총 TODO: 12건
   🔴 높음: 4건 | 🟡 보통: 5건 | 🟢 낮음: 3건
   ⏱️ 총 예상 소요: 약 16시간
   ```

## 다음 작업 제안 (선택형)
생성 보고 후, 후속 작업을 텍스트로 안내하지 말고 **AskUserQuestion 도구로 선택지를 제시**해주세요.
사용자가 선택하면 해당 작업을 즉시 실행하세요:
- **작업 실행 (권장)** → `/plan:execute {작업계획서 경로}` 절차 실행
- **여기서 종료** → 추가 작업 없이 종료
